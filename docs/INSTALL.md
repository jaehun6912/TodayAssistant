# 설치 및 실기기 확인

## 설치

GitHub **Releases**에서 최신 `TodayAssistant-v*-debug.apk`를 내려받습니다. 기존 버전이
설치되어 있다면 삭제하지 말고 APK를 실행해 업데이트합니다. 앱을 삭제하면 기기에 저장한
알림 시각, 대상 선택, 계정 연결과 공지 기준선이 함께 초기화됩니다.

처음 설치할 때 Android가 출처가 확인되지 않은 앱 설치 허용을 요청할 수 있습니다.
APK 설치에 사용한 브라우저 또는 파일 앱에만 일시적으로 권한을 허용한 뒤 설치합니다.

## Galaxy 확인 순서

1. Samsung 캘린더에서 Samsung 계정 일정이 동기화되고 표시되는지 확인합니다.
2. 오늘의 비서를 실행하고 캘린더 읽기 권한을 허용합니다.
3. **설정 → 캘린더 연결 진단**에서 Samsung 계정 후보와 원본 `ACCOUNT_TYPE`을 확인합니다.
4. Samsung 캘린더를 눌러 앞으로 30일 일정이 표시되는지 확인합니다.
5. **설정 → 일정**에서 홈과 일정 브리핑에 포함할 캘린더를 선택합니다.
6. 메일·공지·할 일 기능은 각 설정 화면에서 계정과 알림 시각을 확인합니다.

## 공지 사이트

**설정 → 공지**에서 HTTPS 게시판 목록 주소를 직접 추가할 수 있습니다. 첫 성공 조회는
현재 게시물을 기준선으로만 저장하며 이후 추가된 게시물부터 신규로 알립니다. 기본 사이트는
잠금을 해제한 뒤 이름과 주소를 수정할 수 있고 언제든 앱 기본값으로 복원할 수 있습니다.

로그인 또는 자바스크립트가 필요한 사이트, 날짜와 게시물 링크가 일반 HTML에 포함되지 않은
사이트는 자동 분석되지 않을 수 있습니다.

## 읽기 전용 권한

- Android 캘린더: `READ_CALENDAR`
- Outlook 메일: `Mail.ReadBasic`
- Gmail: `gmail.metadata`
- Microsoft To Do: `Tasks.Read`

`WRITE_CALENDAR`, 메일 쓰기, 할 일 쓰기 권한은 사용하지 않습니다.
